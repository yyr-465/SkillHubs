# 桌面 GUI 外部 QA 清单（Desktop QA Checklist）

> 维护者内部 QA 文档。目的：在真实 Windows x64 + 真实 Tauri 运行环境中，逐项验证沙箱/自动化无法覆盖的桌面行为，产出可复核的验收记录（作为 Phase 14 RC 的证据来源）。
> 更新日期：2026-08-19。适用版本：SkillHub 0.1.5（含 P3-12 修复后的构建）。

## 0. 环境与准备

- 系统：Windows 10/11 x64（建议再加一台干净 VM 做首次使用验证）。
- 构建：本地 `pnpm run tauri:build:qa` 生成带 QA 标签的安装包，或 `pnpm exec tauri dev` 直接跑开发窗口。
- 测试素材：
  - 真实 Skill 目录（含合法 SKILL.md 的文件夹，若干）。
  - 5,000 条 Skill 的 JSON 数据集（用于导入冒烟，可复用 Phase 13 测试数据生成思路）。
- 记录方式：每项填 步骤/预期/实际/截图文件名/时间/PASS 或 FAIL；截图先检查再保存（无用户名、绝对路径、secret）。
- 本清单结果完成度 100% 前，`Implementation Complete / Verification Pending` 状态保持。
