# Incident Response Runbook

A calm, ordered approach to a suspected security incident.

## 1. Triage

Confirm the scope and severity before acting. Record the timeline as you go.

## 2. Contain

- Isolate the affected system or account
- Preserve logs and evidence
- Rotate exposed credentials

## 3. Eradicate and recover

- Identify and remove the root cause
- Restore from a known-good state
- Verify controls before going back online

> This is a documentation-only Skill. It never runs commands on its own.
