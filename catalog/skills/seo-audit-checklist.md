# SEO Audit Checklist

Run through these points when reviewing a page.

## Technical

- [ ] Unique, descriptive title and meta description
- [ ] One canonical `h1` per page
- [ ] Descriptive alt text on meaningful images
- [ ] Fast initial load and readable font sizes

## Content

- [ ] Matches the search intent of the target query
- [ ] Clear headings that outline the structure
- [ ] Internal links to related pages
