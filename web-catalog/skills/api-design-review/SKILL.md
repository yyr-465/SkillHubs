# API Design Review

A focused checklist for reviewing a new or changed API.

## Design

- Consistent naming and resource shapes
- Explicit versioning strategy
- Predictable, documented error responses

## Security

- Authentication and authorization on every endpoint
- Input validation and rate limiting
- No secrets in responses or logs
